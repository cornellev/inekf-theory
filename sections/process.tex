\section{Process Model}

We define the following continuous time (CT) dynamics:

\begin{equation}
  \begin{gathered}
    \dot{\rotmat{W}{B}} = \rotmat{W}{B}\fv{B}{\bsomega}^\wedge \\
    \fv{W}{\dbf{v}}_{\mathcal{B}} = \rotmat{W}{B} \fv{B}{a} + \fv{W}{g} \\
  \fv{W}{\dbf{p}}_{\mathcal{B}} = \fv{W}{v}_{\mathcal{B}}
  \end{gathered}
  \label{eq:ct_dynamics}
\end{equation}

And we know that these dynamics are \textit{group-affine} - that is, that they yield a log-linear error which is bounded - this is further shown in the appendix. If we assume that the input measurements $\fv{B}{\bsomega}$ and $\fv{W}{a}_{\mathcal{B}}$ are constant over some small timestep interval $[t, t + \Delta t]$ (i.e., zero-order hold), then we know that the rotation matrix proopagation is defined exactly:
%%TODO: add citation on how this actually works.

\begin{equation}
  \rotmat{W}{B}(t_k+s) = \rotmat{W}{B,\mathnormal{k}} \exp(s[\bsomega]^\wedge) 
  \label{eq:rot_prop}
\end{equation}

This means that we can substitute this into the discretization of both velocity and position, with $s = u \Delta t$, for some timestep $\Delta t$. For instance, with velocity, the integrand yields:

\begin{equation}
  \int_0^{\Delta t} \exp(s[\bsomega]^\wedge)ds = \Delta t \int_0^1 \exp(u[\bsphi]^\wedge)du = \Delta t \Gamma_1(\bsphi)
  \label{eq:vel_integration}
\end{equation}

And the integral behaves similarly for position. This means that after discretizing, we are left with the following dynamics that obey the $SO(3)$ manifold:

\begin{equation}
  \boxed{
  \begin{aligned}
    R_{k+1|k} &= R_{k|k}\Gamma_0(\bsphi) \\
    \mathbf{v}_{k+1|k} &= \mathbf{v}_{k|k} + \fv{W}{g}\Delta t + R_{k|k}\Gamma_1(\bsphi)\mathbf{a}\Delta t \\
    \mathbf{p}_{k+1|k} &= \mathbf{p}_{k|k} + \mathbf{v}_{k|k}\Delta t + \frac{1}{2}\fv{W}{g}\Delta t^2 + R_{k|k}\Gamma_2(\bsphi)\mathbf{a}\Delta t^2 \\
    \hat{\bstheta}_{k+1|k} &= \hat{\bstheta}_{k|k}
  \end{aligned}
  }
  \label{eq:dt_dynamics}
\end{equation}
